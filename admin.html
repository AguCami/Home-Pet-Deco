Empezar de nuevo

Descarta todo lo que cargaste acá, incluidas las fotos, y vuelve al catálogo que está publicado.

Cargar un producto

  1. Tocá + Nuevo.
  2. Subí la foto: se recorta cuadrada y se comprime sola. Podés usar la foto original del celular.
  3. Completá nombre, precio, resumen y descripción. Elegí los colores.
  4. Mirá abajo la vista previa: así se va a ver en el catálogo.
  5. Cuando termines, tocá Publicar cambios.

Publicar

El panel arma un ZIP con el catálogo y las fotos, ya ordenado en las carpetas del sitio.

  1. Tocá Publicar cambios y descargá el ZIP.
  2. Descomprimilo en tu computadora.
  3. En GitHub, entrá al repositorio y tocá Add file → Upload files.
  4. Arrastrá la carpeta assets tal cual salió del ZIP.
  5. Commit changes y esperá un par de minutos.

Cuidado con esto

  • Lo que cargues vive solo en este navegador hasta que publiques. En otra computadora no vas a ver estos cambios.
  • Si borrás los datos de navegación del navegador, se pierde el borrador y las fotos sin publicar.
  • El identificador no se puede repetir entre productos.
